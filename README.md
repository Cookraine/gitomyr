# Проєкт авторизації (Docker + Nginx)

Цей проєкт є частиною практики з налаштування серверної інфраструктури. Він містить контейнеризовану сторінку входу з використанням Nginx як веб-сервера.

## Склад проєкту
- `login.html`: Головна сторінка авторизації.
- `styles.css`: Стилі інтерфейсу.
- `nginx.conf`: Налаштування веб-сервера (MIME-типи, root, логи).
- `docker-compose.yml`: Інструмент контейнеризації.

## Як розгорнути

1. Переконайтеся, що у вас встановлено **Docker** та **Docker Compose**.
2. Створіть файл .env поруч із файлом docker-compose.yml та задайте наступні параметри:
   ```env
   APP_HTTP=8080 # за змовчуванням
   ```
3. Запустіть проєкт командою:
   ```bash
   docker-compose up -d --build
   ```
